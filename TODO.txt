*** Notes ***
How to run angular app in VS Code:
    NPM SCRIPTS server

How to run web component:
    run path-example-express to have backend on port 8082
    ng build --output-hashing none --optimization=false
    cd dist/path-framework
    (npm install -g serve)
    serve

*** Release ***
    Increase version number in /package.publish.json
    Run package.json: release
    Run npm publish in dist/release
